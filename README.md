# Задача
Написать программу на любом языке программирования, которая способна запуститься на неизвестном хосте, отработать 5 секунд, собрать и эксфильтровать следующие данные:

1. 5 секунд аудиозаписи со встроенного микрофона. 
2. Скриншот экрана
3. Содержимое буфера обмена
4. Нажатые за 5 секунд клавиши

Обратите внимание: на встроенный микрофон будет передаваться сигнал с воспроизводящего устройства по виртуальному кабелю.
# Ход работы
Было реализовано три компонента итоговой программы:
- Логгер, для отслеживания удачных и неудачных событий сбора информации
- Коллектор, основная часть программы реализующая выполнение функций по сбору информации
- Отправитель, часть программы, отвечающая за отправку собранной информации архивом на указанную почту
Для реализации основной части программы были использованы библиотеки:
- pyautogui для снимка экрана 
- pyaudio для записи аудио
- keyboard для логирования нажатых клавиш
- pyperclip для мониторинга буфера обмена
- pygetwindow для отслеживания положения окон
- cv2 для снимка с веб-камеры
Реализация отправки была сделана через почту Gmail. Была создана отдельная почта mokaiv118@gmail.com и для неё пароль приложения, чтобы через API обращаться к сервисам Gmail для отправки сообщений.
# Результат
Была реализована программа собирающая следующую информацию, и отправляющая её на почту злоумышленника:
- 5 секунд аудиозаписи микрофона
- скриншот экрана
- содержимое буфера обмена (и его история если он изменялся во время работы программы)
- логирование нажатых клавиш
- снимок с веб-камеры
- расположение и имена окон приложений
